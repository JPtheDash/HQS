HOW TO USE
- Paste one prompt at a time into your image generator (Midjourney / DALL·E /
  SDXL / Leonardo, etc.).
- Keep the STYLE line identical across everything so the whole game looks like
  one world.
- BACKGROUNDS: landscape ~2:1 (e.g. 1774x896 or 2048x1024). They scroll as a
  parallax layer, so the bottom ~15% is hidden behind the ground — don't put
  anything important there. No characters in backgrounds.
- SPRITES (enemies/props): plain flat background is fine — a grey/dark
  checkerboard, solid magenta, or real transparency. My tools strip checker/solid
  backgrounds automatically, so don't worry about perfect alpha.
- For animated enemies, ask for a GRID sprite sheet (rows = actions) exactly like
  the bat sheet, all frames the SAME size, character CENTERED in each cell,
  facing LEFT (they move toward Hanuman, who faces right — I can flip in code).
