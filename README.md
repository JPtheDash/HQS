# Hanuman: Quest for Sanjeevini

A 2.5D side-scrolling mobile platformer inspired by the Ramayana episode of
Hanuman's flight to fetch the Sanjeevini herb. Built with [Phaser 3](https://phaser.io)
and [Vite](https://vitejs.dev), packaged for Android with [Capacitor](https://capacitorjs.com) -
the same stack as the sibling Little Krishna's Butter Hunt project.

## Status

Early playable slice: opening cinematic, Home screen, and one full chapter
(Ashoka Vatika forest) with the core movement set. **There is no illustrated
art yet** - every texture in the game is drawn procedurally at boot by
[`src/game/PlaceholderArt.js`](src/game/PlaceholderArt.js), so the game is
playable and its level layouts are judgeable before a single commissioned
asset exists. See that file's header comment before adding real art.

## Running it

```
npm install
npm run dev
```

Then open the printed local URL. In a Codespace, use `tools/serve.sh`
instead - see its header comment for why a plain `vite --host` isn't enough
to get a phone-reachable link out of a Codespace tunnel.

## Controls

Hanuman runs by himself - there is no left/right input. Everything is one
finger, on the whole screen:

- **Tap** - jump. Tap again in mid-air - double jump.
- **Hold** (after leaving the ground) - fly, at the cost of stamina.
- **Swipe down** while airborne - dive, for a fast drop.

## Gameplay systems

- **Health** - lost to thorn bushes, boulders, fire, and falling into a gap.
  Restored by herbal plants.
- **Stamina** - drained by flight, regenerated by standing on the ground (or
  faster from bananas/mangoes). Flight cuts out at zero.
- **Coins & lotuses** - collected for score; lotuses are worth more.

## Project layout

- `src/scenes/` - `Boot` generates the placeholder art, `Home` is the title
  screen, `Cinematic` plays the opening story beats, `Game` is the level
  itself, `LevelComplete` shows the run's outcome.
- `src/data/level1.js` - the first chapter's layout (ground, platforms,
  obstacles, collectibles), kept as data rather than inline in `GameScene` so
  new chapters are new files, not new code.
- `src/game/PlaceholderArt.js` - every texture, generated at runtime.
- `tools/probe.mjs` - a headless Playwright smoke test: loads the game,
  plays through the cinematic and a few seconds of level 1, and fails on any
  console error.
